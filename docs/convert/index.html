    Are my images uploaded?

    No. Conversion runs in your browser with the same code as the Save Image As extension. The page's Content-Security-Policy only lets it load its own files, so it has no way to send yours anywhere.

    Which files can I convert?

    Anything your browser can open: WebP, AVIF, PNG, JPG, GIF (first frame) and BMP. HEIC photos from iPhones aren't supported in Chrome yet.

    What does "Under 1 MB" do?

    It finds the highest quality that fits under 1 MB and saves a WebP, which is handy for email and chat attachments.
