How it works

Set it once.
Then it's one click.

  1. 1

    Pin it

    Click the puzzle icon in Chrome's toolbar and pin Save Image As.

  2. 2

    Pick your format

    Choose PNG, JPG, WebP, AVIF, PDF or Original, and a folder inside Downloads.

  3. 3

    Right-click and save

    Use the one-click item, or pick any other format from the same menu. Want it even faster? Switch on "One-click only".

FAQ

Questions

Does it upload my images?

No. The image is fetched from the site it's on and converted inside your browser. Nothing is sent to us or anyone else.

Where do saved files go?

Into Downloads, or a folder inside it that you name. Choose "Ask where" in the popup to pick a location every time.

Why does Chrome save some images as .webp?

Many sites serve WebP because it loads faster. Save Image As converts it to PNG, JPG, AVIF or PDF so the file opens anywhere.

Why might it ask to "Allow on all sites"?

Some sites block extensions from reading image files. If a save is blocked, the popup offers this one permission. It's optional and stays off until you click it.

Looking for a "Save image as Type" alternative?

Save Image As does the same job, right-click and pick a format, with conversion on your device, the full-resolution image and minimal permissions.
