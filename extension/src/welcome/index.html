You're set up 🎉

Three quick steps and you're saving images in seconds.

  1. 1

    Pin it

    Click the puzzle-piece icon in your toolbar, then pin Save Image As so it's always one click away.

  2. 2

    Set your defaults

    Open the popup and choose your save mode, default format, and folder — it takes about ten seconds.

  3. 3

    Try it

    Right-click any image on any page. Pick a format, or use the one-click "Save as…" item.
